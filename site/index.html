Designed for epistemic clarity

AI accelerates the work. You remain the author of the knowledge system.

01

Source grounded

Claims from papers retain evidence anchors so they can be checked against the original source.

02

Epistemically explicit

Reported evidence, author interpretation, reader synthesis, and speculation are not treated as equivalent.

03

Review before permanence

Permanent-note candidates pass structural gates and remain subject to human approval.

04

Graph honest

Existing connections are distinguished from suggested new concepts; RoamPrompt does not pretend links already exist.

Get started

Bring your own Gemini API key.

RoamPrompt uses a user-provided Google Gemini API key. The key is entered through the extension settings in Roam Research; Puli AI does not provide a shared key or receive your source documents through this website.

Read the privacy documentation →
  1. 1
    Install from Roam Depot

    Installation instructions will be published once the Depot listing is approved.

  2. 2
    Add your API key

    Open RoamPrompt settings and enter your own Google Gemini API key.

  3. 3
    Choose a workflow

    Convert a block, use the Ambient Assistant, or attach a supported academic PDF.

  4. 4
    Review the result

    Verify notes, citations, evidence locators, and interpretations before relying on them.
