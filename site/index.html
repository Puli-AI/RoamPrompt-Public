Bring your own Gemini key

Your account. Your quota. Your key.

RoamPrompt does not supply a shared key. Create your own Gemini API key with Google, then enter it only in the RoamPrompt extension settings. Puli Consulting does not receive that key through this website.

Google’s official API-key guidance ↗
  1. 1
    Open Google AI Studio

    Sign in, accept Google’s terms, and open API Keys.

  2. 2
    Create your key

    Create a key in an appropriate Google Cloud project and copy it securely.

  3. 3
    Apply it in Roam

    Open Roam Research → Settings → Roam Depot → RoamPrompt, then paste it into the Gemini API Key setting.

  4. 4
    Protect and monitor it

    Never put it in a Roam block, screenshot, or GitHub repository. Review quota and billing; rotate it immediately if exposed.
